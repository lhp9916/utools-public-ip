# 公网 IP · 商店资料

## 基本信息

- **插件应用名称**：公网 IP
- **一句话简介**：进入即查询并复制当前公网 IP，附带地区与运营商归属。
- **关键词**：公网IP、我的IP、ip、myip、查IP
- **支持平台**：Windows / macOS / Linux

## 应用介绍

公网 IP 是一款轻量的网络信息查询工具。打开插件后自动请求最新公网 IP，查询成功后直接写入剪贴板，省去手动复制的步骤。

结果同时展示 IP 所属国家、省份、城市和运营商，适合排查网络出口、配置端口映射、填写白名单或与远程同事核对网络环境。

### 功能特性

- 进入插件自动查询，无需手动点击
- 查询成功后自动复制 IP，也可点击「复制」按钮或 IP 再次复制
- 展示国家、地区、城市与运营商归属
- 显示本次查询时间与数据来源
- 请求带时间戳，避免拿到缓存结果
- 适配 uTools 浅色与深色主题
- 不读取剪贴板、不收集或上传任何用户数据

### 使用方法

1. 在 uTools 搜索框输入 `公网IP`、`我的IP`、`ip`、`myip` 或 `查IP`
2. 进入插件后等待查询完成
3. IP 会自动复制到剪贴板，可直接粘贴使用；也可点击 IP 或右侧「复制」按钮再次复制

### 数据来源与隐私说明

- 查询接口：`https://myip.ipip.net/json`
- 插件仅向上述接口发起 HTTPS 请求以获取当前公网 IP 与归属地，不收集、不存储、不上传任何用户数据
- 插件只向剪贴板写入查询到的 IP，不读取剪贴板内容
- 无账号体系、无埋点统计、无广告
